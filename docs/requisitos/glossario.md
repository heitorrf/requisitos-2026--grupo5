# Glossário — UniShare

**Grupo 5 · Versão 1.0 · 25/11/2026**

> Proposta acadêmica para revisão; não representa validação por usuários reais.

## Histórico de versões

| Data | Versão | Descrição | Autor |
| --- | --- | --- | --- |
| 25/11/2026 | 1.0 | Consolidação e alinhamento com a visão 4.0 | Grupo 5 — proposta |

| Termo | Definição |
| --- | --- |
| Ator | Papel externo à fronteira do sistema que participa de um caso de uso. |
| Ator abstrato | Generalização de papéis que compartilham comportamento, não um perfil adicional de conta. |
| Visitante | Pessoa interagindo sem sessão ativa. |
| Estudante local | Usuário estudante vinculado ao contexto local. |
| Estudante intercambista | Usuário estudante em experiência de intercâmbio. |
| Candidato a professor | Conta acadêmica sem autorização docente efetiva. |
| Professor | Usuário com autorização docente concedida. |
| Administrador | Responsável operacional com permissões restritas. |
| Conexão | Vínculo aceito pelos dois usuários. |
| Grupo de estudo | Espaço de colaboração social aberto ou restrito. |
| Turma | Espaço acadêmico gerido por professor autorizado. |
| Atividade | Tarefa de turma com instruções, prazo e pontuação máxima. |
| Entrega | Resposta submetida pelo estudante a uma atividade. |
| Nota interna | Resultado acadêmico registrado no UniShare, sem validade oficial. |
| Comunicado | Aviso vinculado à turma. |
| Feed | Lista de publicações acessíveis. |
| Guia de adaptação | Catálogo de orientações, locais, serviços e pontos turísticos. |
| Oportunidade | Divulgação de evento, vaga, projeto ou atividade acadêmica. |
| Recomendação | Sugestão de referência baseada em área e interesses. |
| Tradução sob demanda | Versão auxiliar solicitada pelo usuário, sem substituir o original. |
| Denúncia | Registro de conteúdo ou comportamento para análise de moderação. |
| Bloqueio | Restrição de novas conexões e mensagens diretas entre usuários. |
| NEC / F / RF / CDU | Necessidade, funcionalidade, requisito funcional e caso de uso. |
| RN / RNF | Regra de negócio e requisito não funcional. |
| SRS | Especificação de Requisitos de Software. |
| Wireframe | Representação de baixa fidelidade da disposição e organização dos elementos da interface. |
| Mockup | Representação estática de alta fidelidade da interface; não executa fluxos. |
| Protótipo navegável | Simulação interativa de interface e comportamento; não integra o pacote estático. |
